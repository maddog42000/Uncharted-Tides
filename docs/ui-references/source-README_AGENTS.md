# Uncharted Tides — Agent Asset Implementation Guide

This archive contains the master asset manifest and mapping context for Uncharted Tides (Godot 4.7.2).

## Folder Placement Instructions for Manus:
Place all custom PNG assets into the project directory as follows:
- `res://assets/sprites/items/` (32x32 px items, ores, bars, planks, cannonballs, currency)
- `res://assets/sprites/ships/` (128x128 px ship icons)
- `res://assets/sprites/ui/` (48x48 px navigation tab glyphs)

Refer to Uncharted_Tides_Asset_Manifest.json for exact filename-to-context mappings.
